# Booking Changes

> Fictional policy for Puerto Azul Travel, a made-up agency used as demo data.

## Name corrections

Minor name corrections, such as one or two misspelled letters, are free if requested within 24 hours of booking. After 24 hours, the airline's name change rules apply, and many airlines treat any name change as a new ticket.

## Date changes

Date changes on vacation packages are allowed up to 21 days before departure, subject to availability. The agency charges a change fee of USD 40 per booking, plus any price difference from hotels or airlines.

Inside 21 days before departure, a date change is treated as a cancellation followed by a new booking.

## Adding travelers

Travelers can be added to an existing booking while space is available. Each added traveler pays the current price, which may be higher than the original price.

## Who can approve changes

Advisors can process name corrections and date changes. Changes that waive a fee require supervisor approval.
